🏛️ The Architecture Content Framework in Practice

In classical enterprise architecture, tables and models must not exist as unclassified presentation widgets. Under The TOGAF® Standard Architecture Content Framework and Consortium Rule DEL-04, every structured table represents a formally classified Architecture Artifact (Catalog, Matrix, or Register/Log) belonging to an approved TOGAF Deliverable.

This appendix provides complete bi-directional lineage: identifying which ADM Phase produces each table, which downstream phases consume it as an architecture mandate, and which formal handshake governs the handover.
